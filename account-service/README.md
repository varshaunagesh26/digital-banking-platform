# Account Service

The **Account Service** is a RESTful microservice responsible for managing account service related objects. It provides a centralized API layer for creating, reading, updating, and deleting **Accounts**, **Customers**, and **Branches** within the system.

## Features

- **Account Management** — Create and manage bank accounts, including account details, status, and balance tracking.
- **Customer Management** — Handle customer profiles, personal information, and their associated accounts.
- **Branch Management** — Manage branch information, including location details and branch-to-account relationships.

## Tech Stack

- **Language:** Java 21
- **Framework:** Spring Boot
- **Database:** PostgreSQL
- **Containerization:** Docker / Docker Compose
